# Flipcord

FLIP! Your layout is now reversed!

<img width="1918" height="1198" alt="image" src="https://github.com/user-attachments/assets/0509ca0e-89eb-4213-b04f-602ac38b9759" />

Flipcord is a Discord theme that mirrors the vanilla discord layout, reversing the order of the elements.
It was originally made on request for user `@sachet2t` in the BetterDiscord server before discord's mega UI overhaul.

People seemed fond of it, even after the overhaul, but I wasn't skilled enough to figure out how to actually work with the new UI placements.

Fast forward to now, roughly a year later, and afer I've learned a lot more about how to do CSS, User `@_.poptarts._` requested a revival.
I figured it was worth a shot!
